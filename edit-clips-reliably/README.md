# Clips: Edit New Clips Reliably

> **Built against**: Bitwig 6.1.4 (Windows x64)
>
> **Will map to**: All Bitwig versions Patchbay supports on Windows, Mac and Linux
>
> **Mod ID**: edit-clips-reliably
>
> **Prerequisites**: None

## What does this do?

There are many occasions where opening a clip to edit it results in the Detail Editor opening but the clip not being focused, requiring you to go and find it.

**Clips: Edit New Clips Reliably** opens the Detail Editor first and then hands the new clip to the editor that is showing so the clip is always in view.

## How do you use it?

Just enable it and it works.
