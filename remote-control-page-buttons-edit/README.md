# Device: Right-Click Page Buttons to Edit Remote Controls

A right-click on the Previous or Next page button of a device's Remote Controls opens Bitwig's Remote Controls editor.

- Mod ID: `remote-control-page-buttons-edit`
- Built against Bitwig 6.1.4, Windows x64.

## What it does

- **Right-click Previous or Next** opens Bitwig's Remote Controls editor. The pointer help shows it: `CLICK Prev page  RIGHT-CLICK Edit Remote Controls`.
- **Right-click with Shift, Ctrl or Alt** (or two of them) does nothing and shows no pointer help.
- A plain click still changes the page.

Bitwig shows these buttons only in Mapping mode. To keep them visible all the time, add **Device: Always Show Remote Control Page Buttons**.
