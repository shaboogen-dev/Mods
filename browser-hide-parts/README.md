# Browser: Hide Parts

Hides parts of the side browser you don't use.

- Mod ID: `browser-hide-parts`
- Built against Bitwig 6.1.4.
- Needs **Framework: Settings** 1.0.0 and **Framework: Browser** 0.3.0-dev.1 or later, which Patchbay ticks with it.

## Settings

Settings → **Mods** → **Hide Browser Parts**. Each option applies at once.

| Option | When ticked |
|---|---|
| Hide Quick Sources | the Quick Sources toolbar is hidden and F1–F9 do nothing |
| Hide filters | the filter area is hidden, the filters are cleared, and the filter shortcuts, the suggestions that set a filter and the results' drill-down arrows are off |
| Hide search suggestions | no suggestions in the side browser's search field |
| Hide details pane | the details pane is hidden and its shortcut does nothing (favourites and collections stay in a result's context menu) |

Nothing is hidden until you tick it. Turning the mod off brings every part back.

A browser view another mod offers (Settings → Mods → Browser → Browser view) may show or hide some of these parts itself; while that view is chosen, its choice wins.
