# Detail Editor: Open Maximised

Whenever Bitwig opens a clip in the Detail Editor, it opens maximised, as the main content:
- a double-click on a clip, in the arranger or the clip launcher;
- a new clip, when Bitwig's own **Automatically open new clips in Detail Editor Panel** (Settings > Behaviour > Defaults) is on;
- Bitwig's actions that open a clip or track in the Detail Editor.

It goes to EDIT, as Bitwig's own **Toggle maximized editing mode** does. With **Panel: Streamlined Views** that is the Detail Editor alone, in place of the views shown before. The device panel is left as it is. In a display profile without an EDIT mode, Bitwig opens the Detail Editor as it always does.

Turned off, Bitwig opens the Detail Editor as it always does. Nothing is saved in projects.

Built against Bitwig 6.1.4 (Windows).
