# Detail Editor: Open Maximised

> **Built against**: Bitwig 6.1.4 (Windows x64)
>
> **Will map to**: All Bitwig versions Patchbay supports on Windows, Mac and Linux
>
> **Mod ID**: open-detail-editor-maximised
>
> **Prerequisites**: **Framework: Settings** 1.0.0 or later.

## What does this do?

Typically, when a Launcher or Arranger clip is opened in the Detail Editor, it is opened as a part of the screen. To open the clip full screen requires using another shortcut.

**Detail Editor: Open Maximised** adds a setting that defaults to opening the Detail Editor maximised instead.

## How do you use it?

* The setting is in **Settings > Mods > Open Detail Editor Maximised > Automatically open Detail Editor maximised**.
* While it's ticked (the default when the mod is installed), anytime that a clip is opened it opens maximised instead.
* While it's unticked, Bitwig opens the Detail Editor exactly as it does without the mod.

## Things to note

* In a display profile that has no maximised editing mode, Bitwig opens the Detail Editor as it always does.
* Older versions of the **Panel: Streamlined Views** (0.4.0-dev.9 and previous) mod include this functionality. These mods cannot be used together.
* When using the **Panel: Streamlined Views** mod, the maximised Detail Editor is shown on its own, in place of other views that may currently be open.
