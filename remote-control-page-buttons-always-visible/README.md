# Device: Always Show Remote Control Page Buttons

> **Built against**: Bitwig 6.1.4 (Windows x64)
>
> **Will map to**: All Bitwig versions Patchbay supports on Windows, Mac and Linux
>
> **Mod ID**: remote-control-page-buttons-always-visible
>
> **Prerequisites**: None

## What does this do?

Previously, Bitwig showed Previous and Next buttons that allowed you to be able to cycle through a device's Remote Control pages. For some reason, these were removed in a later update of Bitwig and could only be accessed when mapped through Mapping mode.

**Device: Always Show Remote Control Page Buttons** restores the original functionality and keeps them visible all the time. It also adds the ability to right click a button to open or close Bitwig's Remote Controls editor.

## How do you use it?

* Click the Previous or Next buttons to change Remote Control pages.
* Right click either button to open the Remote Controls editor
* Right click again to close it.

## Things to note

* The page name between the buttons still opens Bitwig's Pages menu, as it normally does.
