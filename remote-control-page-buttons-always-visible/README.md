# Device: Always Show Remote Control Page Buttons

Keeps the Previous/Next page buttons of a device's Remote Controls visible at all times, not only in Mapping mode. Clicking them changes the page as in Bitwig, and the page name between them still opens Bitwig's Pages menu.

- Mod ID: `remote-control-page-buttons-always-visible`
- Built against Bitwig 6.1.4, Windows x64.

To open the Remote Controls editor with a right-click on these buttons, see **Device: Right-Click Page Buttons to Edit Remote Controls**.
